Carve 0.1.3
===========

Syntax updates for the current Carve 0.1.x block and inline rules.

New
  - Inline literals and bare-dot ordered markers are highlighted.

Fixes
  - Symbol boundaries and the symbol scope name were wrong.
  - Comment fences, blockquote spacing, empty markers, tab separators,
    thematic breaks, roman markers, attributed markers, task states and
    abbreviation terms all mis-scoped.

Internal
  - The shared block battery is asserted here too, and the syntax-test
    linter is stricter.

This message was added late: 0.1.3 shipped without one, so it appears
alongside the 0.1.4 message on an upgrade from 0.1.2.
