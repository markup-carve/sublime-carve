# Carve for Sublime Text

Carve syntax support for Sublime Text 4 build 4050 or later. The package uses the maintained Carve TextMate grammar. See the [Carve documentation](https://markup-carve.github.io/carve/) for the markup language.

## Features

- Highlighting for `.crv` files and embedded fence languages.
- Formatting, import, and navigation commands.

## Install

In Package Control, run **Install Package** and select **Carve**.

## Usage

Open a `.crv` file; Sublime selects the Carve syntax automatically.
